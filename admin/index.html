Для немедленной работы можно использовать fine-grained token с доступом только к cozy-atelier и разрешением Contents → Read and write. Вводи его только на своём сайте, не присылай в чат. Токен хранится исключительно в оперативной памяти открытой вкладки и исчезает при перезагрузке.
