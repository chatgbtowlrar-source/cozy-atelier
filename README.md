# Cozy Atelier — публичный сайт

Подготовлено для GitHub Pages на основе Cozy Atelier v8.3.

Публикация через GitHub:
1. Разместите **содержимое этой папки** в корне ветки `main` репозитория `chatgbtowlrar-source/cozy-atelier` (не ZIP-файл и не саму папку).
2. В GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите `main` и `/ (root)`, нажмите **Save**.
3. Подождите несколько минут. Сайт должен появиться по адресу https://chatgbtowlrar-source.github.io/cozy-atelier/ (после активации GitHub Pages).

Публичная версия содержит только статические HTML/CSS/JS, изображения и `data/site.json`.

**Админка НЕ включена**: существующая `admin.html` требует локальный Python API и не будет безопасно работать на GitHub Pages. Изменения прайса/работ для этой версии вносятся в `data/site.json` и соответствующие изображения и публикуются новым коммитом.

**Важно:** опубликованный сайт может быть просмотрен всеми. Избегайте публикации паролей, секретов, приватных файлов и исходной локальной базы заказов.
