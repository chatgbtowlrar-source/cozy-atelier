# Cozy Atelier

Авторский сайт-портфолио художника Кози: иллюстрации, стикеры и персонажи на заказ.

Сайт готовится к публикации на **GitHub Pages** на основе версии **8.3**. Для публичного сайта нужны статические HTML, CSS, JavaScript, изображения и `data/site.json`.

> Важное замечание: GitHub Pages не запускает Python. Локальная админ-панель и серверные файлы не должны публиковаться как работающая онлайн-админка без отдельной защищённой серверной части.

## Публикация

После загрузки содержимого публичной сборки в корень `main`: **Settings → Pages → Deploy from a branch → main → / (root)**.

Ожидаемый адрес после включения GitHub Pages: https://chatgbtowlrar-source.github.io/cozy-atelier/
